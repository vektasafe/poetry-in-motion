# Poetry in Motion: One‑Page Strategy

**Primary revenue model:** Commission on gross merchandise value (GMV).  
**Target customer:** Nairobi woman, 25–40, buys fashion online occasionally, frustrated by fit and limited local creator visibility.  
**Wedge (12‑month focus):** AI‑assisted style quiz + curated micro‑catalog (12 SKUs, 5 creators) → M‑Pesa checkout → WhatsApp‑native sharing.  
**Deferred:** live sessions, subscriptions, trade‑in logistics, global resale, AR try‑on, national marketplace scale, EAC expansion, 37+ API routes.  
**Creator share:** 40–50% of GMV (to be validated with unit economics spreadsheet).  
**Unit economics target:** AOV ≥ KES 3,500, return rate ≤ 15%, take rate 10–18%, M‑Pesa fee ≤ 2%, shipping ≤ KES 300, creator share 40–50%.  
**Phase 2 success criteria:** 5 creators onboarded, 12+ real SKUs, quiz persisted, M‑Pesa checkout live, WhatsApp order status functional, ODPC registration complete, DEMO_MODE flag implemented, all P0 honesty requirements met, unit economics spreadsheet built, return rate measured from first 50 orders.
